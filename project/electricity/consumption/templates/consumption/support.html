Frequently Asked Questions

Quick answers to help you get started

How does EnergySync predict electricity consumption?

EnergySync uses machine learning models and historical electricity consumption records to estimate future usage. The prediction feature uses a Random Forest Regressor.

How can I add electricity consumption?

Open Add Usage to enter your electricity consumption manually. You can also import supported household consumption data through the dataset import feature.

What is anomaly detection?

Anomaly detection identifies unusual electricity consumption patterns using an Isolation Forest model. It helps you notice unexpected changes in energy usage.

How can I reduce electricity waste?

Review your consumption history, anomaly detection results and energy-saving recommendations to identify unusual usage and opportunities to save electricity.

Can I change my account password?

Yes. Open Account Settings and select Change Password to update your account password securely.
